MODULE: Ncurses
PURPOSE: Terminal UI, screen management, and keyboard handling using the ncurses library.

This module provides a direct 1:1 mapping of the standard C ncurses API to y--.
Functions that return or accept WINDOW pointers in C represent them as `int` in y--
(by casting the pointer to long long and then int).  You should store these
ints in variables and pass them back to functions expecting a `win` argument.

Import examples:
    import Ncurses

────────────────────────────────────────────────────────────────────────────
INITIALIZATION & CLEANUP
────────────────────────────────────────────────────────────────────────────

initscr() -> int()      - Initializes ncurses, sets up standard screen (stdscr),
                          calls cbreak(), noecho(), keypad(stdscr, true), and
                          returns the stdscr pointer as an int.
endwin() -> none()      - Ends ncurses mode and restores terminal state.
isendwin() -> bool()    - Returns true if endwin() was called.
