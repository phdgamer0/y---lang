MODULE: Math
PURPOSE: Mathematical functions and physical constants.

Constants exported by the Math module:
    PI          = 3.141592653589793   (π)
    E           = 2.718281828459045   (Euler's number)
    PHI         = 1.618033988749894   (Golden ratio)
    G           = 6.6743e-11          (Gravitational constant, m³ kg⁻¹ s⁻²)
    G_EARTH     = 9.80665             (Standard gravity, m/s²)
    EPSILON_0   = 8.8541878128e-12    (Vacuum permittivity, F/m)
    PLANCK_H    = 6.62607015e-34      (Planck constant, J·s)

All angle arguments and return values are in RADIANS unless otherwise noted.
All functions accept int(), float(), bigint(), and bool() arguments; bool is
coerced to 1.0 (true) or 0.0 (false).  bigint() is converted via std::stod,
which may return INFINITY for values exceeding double range.

Import examples:
    import Math
    from Math import Sin, Cos, PI

NAME
    Abs - Math module

SYNOPSIS
    int()|float()|bigint() Abs(num: int()|float()|bigint())

DESCRIPTION
    Returns the absolute value of num.  The return type matches the input
    type: int input produces int output, float input produces float output,
    and bigint input produces bigint output.

ARGUMENTS
    num (int()|float()|bigint()) - The value to take the absolute value of.

RETURN VALUE
    Same type as input.

ERRORS
    ArgumentError - if called with any number of arguments other than 1.

EXAMPLES
    Abs(-5)    -> 5
    Abs(-3.14) -> 3.14
    Abs(0)     -> 0

SEE ALSO
    Sgn

NAME
    MapRange - Math module

SYNOPSIS
    float() MapRange(num: float(), in_min: float(), in_max: float(),
                     out_min: float(), out_max: float())

DESCRIPTION
    Linearly maps num from the input range [in_min, in_max] to the output
    range [out_min, out_max].  If in_min == in_max (zero-width input range),
    out_min is returned instead of dividing by zero.

ARGUMENTS
    num     (float()) - Value to map.
    in_min  (float()) - Minimum of the input range (inclusive).
    in_max  (float()) - Maximum of the input range (inclusive).
    out_min (float()) - Minimum of the output range.
    out_max (float()) - Maximum of the output range.

RETURN VALUE
    float() - The mapped value.

ERRORS
    ArgumentError - if called with any number of arguments other than 5.

EXAMPLES
    MapRange(0.5, 0.0, 1.0, 0.0, 100.0)   -> 50.0
    MapRange(5.0, 0.0, 10.0, -1.0, 1.0)   -> 0.0

SEE ALSO
    (none in this module)

NAME
    RoundToPower - Math module

SYNOPSIS
    int()|float() RoundToPower(number: float(), power: float())

DESCRIPTION
    Rounds number to the nearest multiple of 10^power.  For example,
    RoundToPower(1234, 2) rounds to the nearest 100, giving 1200.
    RoundToPower(1.2345, -2) rounds to the nearest 0.01, giving 1.23.

    If power >= 0 and the original value was an int or bigint, the result is
    returned as int(); otherwise it is returned as float().

ARGUMENTS
    number (float()) - Number to round.
    power  (float()) - Power of 10 to round to.  Positive = round to larger
                       units; negative = round to decimal places.

RETURN VALUE
    int() or float() depending on the input type and power.

ERRORS
    ArgumentError - if called with any number of arguments other than 2.

EXAMPLES
    RoundToPower(1234, 2)       -> 1200
    RoundToPower(1.2345, -2)    -> 1.23

SEE ALSO
    Floor, Ceil

NAME
    ConvertToBase - Math module

SYNOPSIS
    string() ConvertToBase(num_str: string(), curr_base: int(), target_base: int())

DESCRIPTION
    Converts the string representation of a non-negative integer from
    curr_base to target_base and returns the result as a string.
    Both bases must be between 2 and 36 inclusive.
    Digits above 9 are represented using uppercase letters (A=10, B=11, …).

    The input string num_str must contain only valid digits for curr_base;
    digits above 9 are accepted in both upper and lowercase.

ARGUMENTS
    num_str    (string()) - The number to convert, expressed in curr_base.
    curr_base  (int())    - Source base, 2–36.
    target_base (int())   - Target base, 2–36.

RETURN VALUE
    string() - The number in target_base.  Returns "0" if the value is 0.

ERRORS
    ArgumentError - if called with any number of arguments other than 3.
    ValueError    - if either base is out of range, or if a digit in num_str
                    is invalid for curr_base.

EXAMPLES
    ConvertToBase("ff", 16, 10)   -> "255"
    ConvertToBase("255", 10, 2)   -> "11111111"
    ConvertToBase("0", 10, 16)    -> "0"

SEE ALSO
    (int method base())
