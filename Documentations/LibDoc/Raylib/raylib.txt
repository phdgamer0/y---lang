MODULE: Raylib
PURPOSE: 2D/3D graphics, audio, input, and windowing using the Raylib game
         development library.

The module is only available when the interpreter is compiled with Raylib
support.  All types used by Raylib functions are represented as instances
with named fields (Color, Image, Texture2D, RenderTexture, Font, Sound, Music).

NOTE: Vector positions accepted by "V"-suffixed functions and DrawTextEx use
the language's native vector() type (a 2-element numeric vector <x, y>).
Rectangle instances are created with the Rectangle() constructor.

Import examples:
    import Raylib

────────────────────────────────────────────────────────────────────────────
CONSTRUCTOR FUNCTIONS
────────────────────────────────────────────────────────────────────────────

Color(r, g, b, a)         - Create a Color instance. r/g/b/a are int (0-255).
Rectangle(x, y, w, h)    - Create a Rectangle instance with fields x, y, width, height.
Image(data_ptr, width, height, mipmaps, format) - Rarely used directly; prefer LoadImage.
Texture2D(id, width, height, mipmaps, format)   - Rarely used directly; prefer LoadTexture.
Font(baseSize, glyphCount, glyphPadding, texture, recs_ptr, glyphs_ptr) - Rarely used directly.
