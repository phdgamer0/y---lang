MODULE: Socket
PURPOSE: Low-level Berkeley socket API for TCP/UDP networking.

The module exposes the following socket-type and protocol constants:
    AF_INET, AF_INET6, SOCK_STREAM, SOCK_DGRAM, SOCK_RAW,
    IPPROTO_TCP, IPPROTO_UDP, SOL_SOCKET, SO_REUSEADDR, SO_BROADCAST

These are numeric constants matching the platform's socket.h values.

Socket objects returned by Socket.create() are SocketObj instances with
the following methods: bind, listen, accept, connect, send, recv, close,
setblocking, setsockopt.

Import examples:
    import Socket

────────────────────────────────────────────────────────────────────────────
NAME
    create - Socket module

SYNOPSIS
    SocketObj() Socket.create(domain: int(), type: int(), protocol: int())

DESCRIPTION
    Creates a socket using the POSIX socket() syscall (::socket on POSIX,
    ::socket on Windows).  Returns a SocketObj instance wrapping the file
    descriptor/handle.

    The returned SocketObj has the following methods:
        bind(host, port)        - Bind to address.
        listen(backlog)         - Mark socket as passive.
        accept()                - Accept a connection, returns new SocketObj.
        connect(host, port)     - Connect to remote address.
        send(data)              - Send data string, returns bytes sent.
        recv(size)              - Receive up to size bytes, returns string.
        close()                 - Close the socket.
        setblocking(bool)       - Set blocking/non-blocking mode.
        setsockopt(level, optname, value) - Set socket option.

ARGUMENTS
    domain   (int()) - Address family (AF_INET, AF_INET6, etc.).
    type     (int()) - Socket type (SOCK_STREAM, SOCK_DGRAM, SOCK_RAW).
    protocol (int()) - Protocol (IPPROTO_TCP, IPPROTO_UDP, or 0 for auto).

RETURN VALUE
    SocketObj() - A socket instance.

ERRORS
    ArgumentError - if called with fewer than 3 arguments.
    RuntimeError  - if socket creation fails.

EXAMPLES
    s = Socket.create(AF_INET, SOCK_STREAM, IPPROTO_TCP)
    s.connect("127.0.0.1", 8080)
    s.send("GET / HTTP/1.0\r\n\r\n")
    resp = s.recv(4096)
    s.close()

────────────────────────────────────────────────────────────────────────────
SocketObj METHODS
────────────────────────────────────────────────────────────────────────────

NAME
    bind - SocketObj method

SYNOPSIS
    none() socketObj.bind(host: string(), port: int())

DESCRIPTION
    Binds the socket to the given host and port using AF_INET/sockaddr_in.
    The host is converted via inet_addr (dotted-decimal string).

ERRORS
    ArgumentError - fewer than 4 total args (self + dummy + host + port).
    RuntimeError  - if ::bind() fails.

────────────────────────────────────────────────────────────────────────────
NAME
    listen - SocketObj method

SYNOPSIS
    none() socketObj.listen(backlog: int())

DESCRIPTION
    Marks the socket as a passive server socket willing to accept up to
    backlog queued connections.

ERRORS
    ArgumentError - fewer than 3 total args (self + dummy + backlog).
    RuntimeError  - if ::listen() fails.

────────────────────────────────────────────────────────────────────────────
NAME
    accept - SocketObj method

SYNOPSIS
    SocketObj() socketObj.accept()

DESCRIPTION
    Accepts a pending connection on a listening socket.  Blocks until a
    client connects.  Returns a new SocketObj for the client connection.

ERRORS
    RuntimeError - if ::accept() fails.

────────────────────────────────────────────────────────────────────────────
NAME
    connect - SocketObj method

SYNOPSIS
    none() socketObj.connect(host: string(), port: int())

DESCRIPTION
    Connects the socket to the remote address host:port.

ERRORS
    ArgumentError - fewer than 4 total args.
    RuntimeError  - if ::connect() fails.

────────────────────────────────────────────────────────────────────────────
NAME
    send - SocketObj method

SYNOPSIS
    int() socketObj.send(data: string())

DESCRIPTION
    Sends data over the socket.  Returns the number of bytes actually sent.

ERRORS
    ArgumentError - fewer than 3 total args.

────────────────────────────────────────────────────────────────────────────
NAME
    recv - SocketObj method

SYNOPSIS
    string() socketObj.recv(size: int())

DESCRIPTION
    Receives up to size bytes from the socket.  Returns an empty string
    if the connection is closed or no data is received (recv returns <= 0).

ERRORS
    ArgumentError - fewer than 3 total args.

────────────────────────────────────────────────────────────────────────────
NAME
    close - SocketObj method

SYNOPSIS
    none() socketObj.close()

DESCRIPTION
    Closes the socket.  Uses closesocket on Windows, ::close on POSIX.

────────────────────────────────────────────────────────────────────────────
NAME
    setblocking - SocketObj method

SYNOPSIS
    none() socketObj.setblocking(blocking: bool())

DESCRIPTION
    Sets the socket to blocking (true) or non-blocking (false) mode.
    On POSIX uses fcntl F_GETFL/F_SETFL with O_NONBLOCK.
    On Windows uses ioctlsocket with FIONBIO.

ERRORS
    ArgumentError - fewer than 3 total args.
    RuntimeError  - if the ioctl/fcntl call fails.

────────────────────────────────────────────────────────────────────────────
NAME
    setsockopt - SocketObj method

SYNOPSIS
    none() socketObj.setsockopt(level: int(), optname: int(), value: int())

DESCRIPTION
    Sets a socket option.  Wraps the POSIX setsockopt syscall.

ERRORS
    ArgumentError - fewer than 5 total args (self + dummy + level + optname + value).
    RuntimeError  - if setsockopt fails.
